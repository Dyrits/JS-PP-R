# Reduce

A personal JavaScript library of static methods built on `reduce()`, simplifying basic operations on arrays and objects.

## About The Project

The methods (from the original README):

- `Reduce.sum(array)` - sum of the numbers in an array.
- `Reduce.flat(array)` - flatten an array by one level.
- `Reduce.deepFlat(array)` - flatten an array recursively.
- `Reduce.regroup(objectsArray, property)` - regroup an array of objects by the values of a given property.
- `Reduce.count(array, value)` - count occurrences of a value in an array.
- `Reduce.countInArray(array, arrayValues)` - count occurrences of given values; returns an object with each value occurring more than once as keys and the counts as values.
- `Reduce.countAll(array)` - count occurrences of each item; returns an object with each item as keys and the counts as values.
- `Reduce.reverse(array)` - reverse an array.
- `Reduce.chunk(array, size)` - chunk an array into nested arrays of a given size.
- `Reduce.invert(object)` - invert the keys and values of an object.

Similar functions are documented on MDN: [Array.prototype.reduce()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/Reduce)
